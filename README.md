# Automation Exercise - Cypress

Projeto simples para praticar testes automatizados com Cypress no site https://www.automationexercise.com.

Casos: TC01, TC02, TC03, TC04, TC05, TC08, TC09, TC10, TC15 e TC16.

## Como executar

1. Instale o Node.js.
2. Rode `npm install`.
3. Rode `npm test`.

Para abrir o Cypress: `npm run test:open`.

Os relatórios ficam em `cypress/reports`. A pasta `node_modules` não precisa ser enviada; ela é recriada com `npm install`.
